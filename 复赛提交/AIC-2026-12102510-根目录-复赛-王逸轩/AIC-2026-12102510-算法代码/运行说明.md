# 算法代码与运行说明

**参赛团队编号**：AIC-2026-12102510　**团队名称**：根目录　**队长姓名**：王逸轩
**赛题**：基于视频大模型的通用视频高光剪辑（复赛）

本目录为复赛提交的**完整可复现代码**。方案为「全帧保留 + 居中裁剪」基线，叠加
**逐视频恒定偏置（红框臂）** 与 **杂乱度绝对阈值门控**；唯一模型是 YOLO11n，
且只用于统计逐帧人数，不参与任何坐标回归。

## 一、文件清单

| 文件 | 作用 |
|---|---|
| `baseline_cv.py` | 生成居中裁剪基线（时间定位 + 构图框），输出 `predictions jsonl` |
| `yolo_experiment.py` | 一次性 GPU 前向，构建逐帧检测缓存 `yolo_test_cache.json` |
| `emit_gated.py` | 在基线上叠加红框臂 + 杂乱门控，并写入 `model_size_mb` |
| `stage_data.py` | 公共几何工具（`crop_size` / `free_axis` / `probe_one`） |
| `eval_local.py` | 本地评测器 / 提交格式自检（`validate` / `score`） |
| `fu_index.json` | 复赛 426 条视频索引（`{video_id, targetRatioWH}`） |
| `fu_metadata.json` | 复赛 426 条视频元信息（`W/H/n_frames/fps/duration`，ffprobe 读取） |
| `fu_base.jsonl` | **已生成**的居中基线（426 条，第 2 步产物，可直接复用免重跑） |
| `fu_yolo_test_cache.json` | **已生成**的检测缓存（426 条，第 3 步产物，可直接复用免重跑） |

依赖关系：`baseline_cv → stage_data`；`yolo_experiment → stage_data, eval_local,
baseline_cv`；`emit_gated → stage_data`。

## 二、一键复现

设赛方复赛测试集根目录为 `<TEST>`，其下含 `jsonl/<id>.jsonl`（内容形如
`{"targetRatioWH":[16,9]}`）与 `video/<id>.mp4` 两个子目录。

> **免重跑说明**：`fu_base.jsonl`（第 2 步产物）与 `fu_yolo_test_cache.json`（第 3 步产物）
> 已随包提供，因此若只是复现最终结果，可**直接跳到第 4 步**，
> 用 `--base fu_base.jsonl --cache fu_yolo_test_cache.json` 生成 `predictions.jsonl`。

```bash
# 0) 依赖
pip install -r ../AIC-2026-12102510-模型文件与运行环境/requirements.txt

# 1) 数据准备（fu_index.json 已随包附带，可直接用；下面两条用于重建）
python3 stage_data.py probe --video-dir <TEST>/video --out fu_metadata.json
python3 -c "import os,json; jd='<TEST>/jsonl'; ids=sorted(int(f[:-6]) for f in os.listdir(jd) if f.endswith('.jsonl')); json.dump([{'video_id':str(i),'targetRatioWH':json.load(open(os.path.join(jd,f'{i}.jsonl')))['targetRatioWH']} for i in ids], open('fu_index.json','w'), ensure_ascii=False)"

# 2) 居中基线：τ=1 逐帧保留、drop-tail 0.08、居中裁剪（纯 CPU）
python3 baseline_cv.py --index fu_index.json --video-dir <TEST>/video \
    --keep-ratio 1.0 --alpha 0 --no-yolo --out fu_base.jsonl

# 3) 检测缓存：一次 GPU 前向，stride=5（无 GPU 时把 --device 改成 cpu）
python3 yolo_experiment.py --build-cache --index fu_index.json \
    --video-dir <TEST>/video --metadata fu_metadata.json \
    --cache fu_yolo_test_cache.json --stride 5 --device 0

# 4) 红框 + 杂乱门控叠加，写入 model_size_mb（阈值 2.0 = 绝对杂乱刻度）
python3 emit_gated.py --base fu_base.jsonl --cache fu_yolo_test_cache.json \
    --metadata fu_metadata.json --threshold 2.0 \
    --weights ../AIC-2026-12102510-模型文件与运行环境/yolo11n.pt --out predictions.jsonl

# 5) 提交前自检：期望 RESULT: PASS、violations: 0、model_size_mb 426/426 行一致
python3 eval_local.py validate --index fu_index.json --pred predictions.jsonl
```

输出 `predictions.jsonl` 即复赛「赛题结果文档」，426 行，每行含
`video_id / targetRatioWH / model_size_mb / predictions`。每行 `predictions[i]` 为
`{"frame": 全局源帧号, "bboxes": [x, y, w]}`，高度由 `h = w · target_h / target_w`
唯一确定，故**不提交高度**。

## 三、算法一句话概括

1. **时间维**：不做取舍，每帧都输出（τ=1）；这一支在本地 val 与线上均显著优于任何抽样。
2. **空间维**：每帧按 `conf × area` 加权池化所有 person 检测，取**逐视频中位数**作为
   该视频唯一的构图中心常数（红框臂）。
3. **门控**：逐帧 person 检出的**均值超过绝对阈值 2.0** 的视频判定为「拥挤、中心无意义」，
   回退为居中裁剪；门控用绝对刻度而非分位数，因为线上测试集拥挤度只有本地 val 的一半。

细节与消融依据见 `AIC-2026-12102510-技术方案.PDF`。
