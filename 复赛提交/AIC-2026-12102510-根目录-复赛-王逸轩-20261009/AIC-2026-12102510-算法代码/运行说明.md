# 算法代码与运行说明

**参赛团队编号**：AIC-2026-12102510　**团队名称**：根目录　**队长姓名**：王逸轩
**赛题**：基于视频大模型的通用视频高光剪辑（复赛）　**日期**：2026-10-09

本目录为复赛提交的**完整可复现代码**。方案在「全帧保留 + 居中裁剪」基线上，叠加了
四条互不冲突的改进：

1. **门控回退**（沿用上一版冠军）：杂乱度超绝对阈值的视频退回居中裁剪；
2. **单主角/宠物逐帧追踪**：主体清晰的视频把每视频常数框换成逐帧移动框；
3. **竖屏人脸聚焦**：竖屏源裁剪窗只能上下平移，把焦点从「胸腰」上抬到「头/脸」；
4. **首/尾黑屏丢帧**：短时软件的自动片头/片尾（大片黑灰且无主体）不框选。

推理阶段只加载两个权重：**YOLO11n**（检测）与 **Qwen2.5-VL-3B-Instruct**（读摘要，
用于判定「动物做主角」的视频），前者负责全部坐标几何，后者只输出一句中文摘要、
不参与任何坐标回归。

## 二、一键复现

设赛方复赛测试集根目录为 `<TEST>`，其下含 `jsonl/<id>.jsonl`（内容形如
`{"targetRatioWH":[16,9]}`）与 `video/<id>.mp4` 两个子目录。

> **免重跑说明**：第 2–7 步的**全部中间产物**（`fu_base.jsonl`、四个缓存、
> `vlm_summaries_test.json`）均已随包附上，因此若只是复现最终结果，可
> **直接跳到第 8 步**，用这些现成文件生成 `predictions.jsonl`。
> 第 7 步（VLM）是唯一需要 GPU 显存跑大模型的步骤，其余都是轻量检测或纯 CPU 后处理。

```bash
# 0) 依赖
pip install -r ../AIC-2026-12102510-模型文件与运行环境/requirements.txt

# 1) 数据准备（fu_index.json / fu_metadata.json 已随包附带；下面用于重建）
python3 stage_data.py probe --video-dir <TEST>/video --out fu_metadata.json
# （fu_index.json 由 <TEST>/jsonl/*.jsonl 聚合而成，此略）

# 2) 居中基线：τ=1 逐帧保留、drop-tail 0.08、居中裁剪（纯 CPU）
python3 baseline_cv.py --index fu_index.json --video-dir <TEST>/video \
    --keep-ratio 1.0 --alpha 0 --no-yolo --out fu_base.jsonl

# 3) 主检测缓存：一次 GPU 前向，stride=5（无 GPU 时 --device cpu，耗时更长）
python3 yolo_experiment.py --build-cache --index fu_index.json \
    --video-dir <TEST>/video --metadata fu_metadata.json \
    --cache fu_yolo_test_cache.json --stride 5 --device 0

# 4) 宠物低阈值缓存：对「摘要主语是动物」的视频，只检 cat/dog（conf=0.05）
python3 pet_cache.py --summaries vlm_summaries_test.json \
    --video-dir <TEST>/video --metadata fu_metadata.json \
    --out fu_pet_cache.json --conf 0.05

# 5) 竖屏 person 整框缓存：存 top/bh，供人脸聚焦用
python3 face_cache.py --base fu_base.jsonl --video-dir <TEST>/video \
    --metadata fu_metadata.json --out fu_person_box_cache.json --conf 0.25

# 6) 黑屏亮度缓存：逐抽样帧灰度均值 + 暗像素占比
python3 black_cache.py --video-dir <TEST>/video --metadata fu_metadata.json \
    --out fu_black_cache.json --stride 5 --dark-pixel 60

# 7) VLM 摘要：Qwen2.5-VL-3B 逐视频一句中文摘要（需要 GPU；产物 = vlm_summaries_test.json）
python3 vlm_summary.py --dataset test

# 8) 融合出最终预测，并写入 model_size_mb
python3 emit_trace.py --base fu_base.jsonl --cache fu_yolo_test_cache.json \
    --metadata fu_metadata.json --summaries vlm_summaries_test.json \
    --pet-cache fu_pet_cache.json --person-box-cache fu_person_box_cache.json \
    --black-cache fu_black_cache.json \
    --threshold 2.0 --single-thr 0.5 --smooth 15 \
    --head-frac 0.24 --model-size-mb 7166.73 --out predictions.jsonl

# 9) 提交前自检：期望 RESULT: PASS、violations: 0
python3 eval_local.py validate --pred predictions.jsonl \
    --video-dir <TEST>/video --metadata fu_metadata.json
```

输出 `predictions.jsonl` 即复赛「赛题结果文档」，426 行，每行含
`video_id / targetRatioWH / model_size_mb / predictions`。每行 `predictions[i]` 为
`{"frame": 全局源帧号, "bboxes": [x, y, w]}`，高度由 `h = w · target_h / target_w`
唯一确定，故**不提交高度**。

> `run_strategy.sh` 把第 8、9 步对**本地 val** 与**复赛 426 条**各跑一遍并出分，
> 用于回归对比：`./run_strategy.sh emit_trace.py --tag trace_pet --threshold 2.0 ...`。

## 三、算法一句话概括

### 时间维（选哪些帧）
不做主动抽样，每帧都输出（τ=1，仅去掉末尾 8%）；这一支在本地 val 与线上均显著优于
任何抽样（`keep_all` 为 val 最优）。**唯一例外**是首/尾的软件自动片头/片尾：连续若干帧
「暗像素占比 ≥ 0.80 且灰度均值 ≤ 60」**且**该帧无 person/cat/dog 目标（`conf ≥ 0.30`）
时判为黑屏卡，从帧集里剔除。两个条件缺一不可——纯夜戏（灰度均值很低但确有目标）不会
被误丢；纯黑帧上 YOLO 会产生虚假检出（如把噪声报成 person），因此"有目标"一侧足够鲁棒。

### 空间维（每帧框多大、放哪）
沿「自由轴」决定框的位置（横屏源左右移 `x`、竖屏源上下移 `y`）：

1. **门控回退**：逐帧 person 均值超过绝对阈值 **2.0** 的视频判为「拥挤、中心无意义」，
   退回居中裁剪（用绝对刻度而非分位数）。
2. **单主角/宠物逐帧追踪**：主体（person；或 cat/dog）逐抽样帧按 `conf × area`
   加权池化出中心，插值到逐帧再做时序平滑（`--smooth 15`），得到逐帧移动的框。
   动物主语视频**优先追宠物**——即便画面同时有人，也把中心给猫狗（判据见下节）。
3. **人脸聚焦**：竖屏源的 person 框中心原来落在胸腰，改用
   `cy = 框顶 + 0.24 × 框高` 把焦点抬到「脸—胸口之间」（`--head-frac 0.24`）。
4. **其余**（多主体但不挤）沿用 `emit_gated` 的每视频常数框。

### 「动物做主角」的判定
`vlm_summary.py` 用 Qwen2.5-VL-3B 给每条视频生成一句摘要，摘要命中
猫/狗/柯基/犬/宠物/金毛/泰迪/柴犬/哈士奇/边牧/萨摩… 等词条即判为动物主语视频。
这类视频：① 用 `pet_cache.py` 的低阈值（0.05）cat/dog 检出去除远处小宠物丢检的问题；
② 追踪时优先宠物而非主人。词条口径在 `pet_cache.py` / `emit_trace.py` 中完全一致。

细节与消融依据见 `AIC-2026-12102510-技术方案.PDF`。
